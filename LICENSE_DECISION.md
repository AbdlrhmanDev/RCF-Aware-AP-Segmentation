# Software license decision required

No LICENSE file is included in this draft release because the code owner has not chosen license terms and ownership of all contributions is not documented. Without a license, public visibility on GitHub does **not** automatically mean permission to reuse or modify the code.

Before publishing, the code owner(s) should select an appropriate software license (for example MIT, Apache-2.0, or a more restrictive license) **only if they possess the rights to grant it**. Dataset access terms remain separate from code licensing and are not altered by the chosen software license.

Do not include PRAD images or masks in the software repository, regardless of the selected source-code license.
